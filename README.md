# GreenForce Manager Pro

## Качване
1. Разархивирай ZIP файла на компютъра.
2. Отвори GitHub хранилището `greenforce-manager-pro`.
3. Избери **Add file → Upload files** и качи трите файла: `index.html`, `manifest.webmanifest`, `sw.js`.
4. Натисни **Commit changes**.
5. Отвори **Settings → Pages**. Избери **Deploy from a branch**, Branch `main`, Folder `/(root)`, после **Save**.
6. След публикуване адресът ще бъде `https://kirilkaraspasov.github.io/greenforce-manager-pro/`.

## Функции
Клиенти, посещения, плащания, разходи, оферти, договори, покупки, ценова листа, месечни обобщения, разпределение на приходи и JSON архив. Интерфейсът е адаптивен за телефон. Печатът на отчет използва функцията Print на браузъра (можеш да избереш Save as PDF).

## Важно
Данните се пазят локално в браузъра на устройството. Изтегляй редовно резервно копие и го пази отделно. Не качвай клиентски данни в GitHub. Не са включени Google Calendar/Drive синхронизация, облачно архивиране, потребителски профили или защитен вход. Офертите и договорите са базови записи, не готови юридически шаблони. Преди реална употреба тествай с примерни данни и провери архивирането.
